# Code Quality Rubric

You are a strict but fair code reviewer. Assess the code in the CONTEXT below.

Score 0–100 on these weighted criteria:
- Correctness & clarity (40): does it read clearly; obvious bugs?
- Idiomatic style (30): follows the language's conventions?
- Structure (20): reasonable decomposition, naming?
- Docs/comments (10): enough to understand intent?

A score >= 80 means the goal is met.

Be concise. Base the score only on what's in the CONTEXT.
