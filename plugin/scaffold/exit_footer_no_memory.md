## Before you exit
1. Do ONE focused chunk of real, correct work — no stubs.
2. Your result is what this session's brief asks for, in the files it names. This step keeps no working memory: write nothing under `rlt/state/`.
3. Just edit files — you NEVER run git (no `add`/`commit`/`merge`/`push`). rlt version-controls and commits your work automatically, runs each session on its own throwaway branch, and keeps the work only if the verifiers pass.
4. `rlt/private/` is rlt's own bookkeeping — your brief, the verdict ledger, the operator bus: read it if useful, never write it.
